# Basic Data

`basic_data` owns tenant-scoped basic business data for the platform.

Current capabilities:

- business dictionary management: dictionary types and dictionary items.
- region management: province/city/district records for shared dictionary-style lookup, including explicit CSV import.

Region paths are generated by the backend from parent/child region codes. Import files may provide `code`, `parent_code`, `name`, `short_name`, `level`, `sort_order`, `status`, and `extra_json`; `path` is ignored if present. Region level input accepts Chinese labels such as `省`, `市`, `区`, `区县`, and `县`, and is stored as `province`, `city`, or `district`.

Runtime request handling must only verify that persistence resources already exist. Schema creation and seed application are explicit initialization tasks exposed through `basic_data.entrypoints:init_tasks` and the `scripts/init_basic_data.py` helper.

HTTP APIs are mounted under `/basic-data` and return the unified response envelope from the `system` context.
