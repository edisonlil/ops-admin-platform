## Design Context

### Users
Internal product, operations, and review staff use fg-agent to recommend reusable function points, inspect the function point library, and correct recommendation feedback.

### Brand Personality
Precise, calm, operational. The interface should feel like a workbench for repeated review tasks rather than a marketing surface.

### Aesthetic Direction
Light, dense, and utilitarian with clear table scanning, restrained color, and purposeful status accents. Avoid decorative gradients, oversized hero sections, dark neon dashboards, and card-heavy marketing layouts.

### Design Principles
- Put the workflow first: recommendation input, result review, and correction actions should be immediately reachable.
- Make dense data readable with strong alignment, quiet typography, and clear table hierarchy.
- Use color for state and confidence, not decoration.
- Preserve context when correcting feedback so reviewers can compare original recommendation and final function point.
- Keep the layout responsive without hiding core operations.
